# Telecom Intelligence & Fraud Data Platform

A data engineering platform for:

- 4G/5G Network Performance Monitoring
- SIMBox Fraud Detection

## Planned Tech Stack

- Python
- Apache Kafka
- Apache Spark Structured Streaming
- Delta Lake
- MinIO
- PostgreSQL
- Apache Airflow
- Docker

## Project Status

Initial setup and dataset preparation completed.
Data profiling and pipelines are not yet implemented.
